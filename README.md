# Evaluating the Impact of Source Diversity for RAG in Historical Research

Source code for investigating how source diversity in RAG based approaches impacts perspective variation on the task of 
question answering on multilingual historical documents from 1805 to 1819 on the topic of Napoleon Bonaparte. 

Code for data collation and processing is in `data`; code for RAG in `RAG`; code for evaluation in `RAG\evaluation` 

Paper relating to this presented at LREC 2026.
