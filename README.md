# Evaluating the Impact of Source Diversity for RAG in Historical Research

Source code for investigating how source diversity in RAG based approaches impacts perspective variation on the task of 
question answering on multilingual historical documents from 1805 to 1819 on the topic of Napoleon Bonaparte. 


Code for data collation and processing is in `data`, with a list of sources used in `data\datasets_all`  


Code for RAG and retrieval is in `RAG`


Code for evaluation and visualizing results is in `RAG\evaluation` 


Related paper presented as a poster at LREC 2026. Video presentation of poster can be found at [https://imruhi.github.io/posts/2026/03/13/](https://imruhi.github.io/posts/2026/03/13/)
